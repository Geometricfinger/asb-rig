# oiris.link — phone ↔ pod / glasses transport
`ble.py`: BLE GATT service (`6f697269-7300-4c69-6e6b-…01`), RX write-without-response + TX notify, segmenting of Noise frames to the ATT MTU (seq | flags | [length] | payload), reassembly that drops only a damaged frame, `loopback_pair` for tests, `BlessGattServer` (pod, needs a radio, `bless` MIT). `pod_service.py`: pod request handler (thermal frames for the phone's live view; delegates face-match enrollment ops). Byte format shared with `android/core` `BleFraming.kt` via `tests/vectors/ble_framing.json`. Everything on the air is already Noise ciphertext. Tests: `tests/test_link_ble.py`. Radio path untested (needs hardware).
