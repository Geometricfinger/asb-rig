# oiris.security — M-04
`aead` (AES-256-GCM, unique nonces, per-key cap), `keys` (scrypt-wrapped master key, crypto-erase), `channel` (Noise_XX_25519_ChaChaPoly_BLAKE2s, paired-fingerprint check, rekey ≤1,000 msgs/10 min), `hashchain` (HMAC-SHA256 chain + Ed25519 anchors, verify detects edit/delete/reorder/truncation), `panic` (soft/hard panic, 10-fail wipe, signed remote wipe), `ct` (constant-time compare). **Depends on**: cryptography, PyNaCl, noiseprotocol. No custom primitives.

Rotation (D-22, ADR-0054): `keys.StaticKeyManager` keeps the Noise static key sealed under a KeyStore subkey, flags it `rotate_soon` in its last 7 days and `expired` at 90 days; `rotate()` clears the pairing, and `SecureChannel(static_created=...)` / `channel.from_pairing` refuse expired or unpaired keys. `KeyStore.add_slot/unlock_slot` add extra wrappings of the master key (used by the Mac Touch ID gate). `hashchain` anchors every 100 records and at least every 60 s (`tick()` is the timer hook). `tests/test_secret_compare_lint.py` fails the build on `==`/`!=` between secret-like values.
